Создание пустого проекта

Откройте Android Studio и выберите File → New → New Project. Возьмите самый простой пустой шаблон — обычно это «No Activity» в разделе «Phone and Tablet» (в Android Studio не всегда есть отдельный шаблон для консольных приложений Kotlin/JVM).

Назовите проект MyConsoleApplication и нажмите Finish. Дождитесь завершения первичной синхронизации Gradle, прежде чем продолжать.

ℹ️
Первая синхронизация завершится ошибкой — это ожидаемо, ведь далее мы превратим проект из Android-приложения в консольное.

Синхронизация проекта

Нажмите File → Sync Project with Gradle Files (или значок слоника / синхронизации на панели инструментов). Следите за панелью Build внизу — синхронизация должна завершиться без красных ошибок.

✅
Возле fun main() в файле Main.kt должна появиться зелёная стрелка запуска ▶. Это сигнал, что проект корректно настроен как JVM-консольное приложение.
9

Запуск приложения

Запустить приложение можно тремя способами:

  • ▶ нажмите зелёную стрелку в поле рядом с fun main();
  • 🖱 кликните правой кнопкой по Main.kt → Run 'MainKt';
  • ⌨️ из терминала в корне проекта: ./gradlew run (macOS/Linux) или gradlew.bat run (Windows).

Вывод — включая интерактивный запрос имени — появится в панели Run внизу IDE. Введите ответ там и нажмите Enter.

10

Отладка приложения

  1. Кликните в левом поле рядом со строкой (например, val sum = numbers.sum()), чтобы поставить точку останова — появится красная точка.
  2. Нажмите значок 🐞 Debug (рядом с Run) или кликните правой кнопкой → Debug 'MainKt'.

Выполнение приостановится на точке останова. Горячие клавиши панели Debug внизу:

F8Step Over — выполнить текущую строку и перейти к следующей
F7Step Into — войти внутрь вызываемой функции
Shift+F8Step Out — выйти из текущей функции
F9Resume Program — продолжить выполнение программы

Изучайте живые значения в панели Variables или наводите курсор на переменные прямо в редакторе, чтобы увидеть их текущие значения.

!

Устранение неполадок

После синхронизации нет зелёной стрелки запуска
Проверьте вкладку Build на наличие ошибок. Самая частая причина — оставшаяся от исходного шаблона строка id("com.android.application") в файле app/build.gradle.kts — удалите её.
Ошибка «Plugin already on the classpath with an unknown version»
Это значит, что версия плагина Kotlin объявлена более чем в одном месте. Убедитесь, что версия указана единственный раз — в libs.versions.toml, — а оба Gradle-файла ссылаются на неё через alias(libs.plugins.kotlin.jvm), а не через жёстко прописанную строку версии.
readLine() сразу возвращает null
Такое случается при запуске через ./gradlew run без подключённого интерактивного терминала. Запуск из панели Run в Android Studio (зелёная ▶) корректно обрабатывает стандартный ввод (stdin).
📦 Сопроводительный файл: архив MyConsoleApplication.zip содержит полностью готовый рабочий проект из этого руководства — распакуйте его и откройте папку напрямую в Android Studio либо выполните шаги выше, чтобы собрать проект самостоятельно.
